# 🎓 Campus Portal & Semester Registration

An all-in-one Campus Web Application for students, featuring an intuitive **Semester Registration Portal**, hostel clearance workflows, mutual roommate group preferences, document verification, and academic management.

---

## ✨ Features

### 📋 Semester Registration Portal
* **Live Registration Countdown Timer**: A single, prominent real-time countdown ticker at the top of the registration module counting down to the semester deadline.
* **Step 1: Old Hostel Clearance**: Upload old hostel dues receipts and check real-time verification status.
* **Step 2: Mutual Roommate & Preference Group Allotment**: Form 3-member mutual roommate preference groups with instant invitation, response tracking, and status metrics.
* **Step 3: Document Verification & Fee Clearance**: Upload and preview mandatory documents (Fee Receipt, Anti-Ragging Affidavit, Identity Proof) with instant status feedback.
* **Step 4: Final Review & Confirmation**: Review all registration details and generate a unique registration reference ID upon submission (with interactive celebration feedback).

---

## ⚡ Recent Updates

* **Semester Registration Optimization**: Removed the redundant static 2nd timer widget from the Step 2 header banner to streamline the user interface and avoid confusion with the main live countdown ticker.

## 🚀 Local Development

### Prerequisites
* Node.js (v18+ recommended)
* npm / yarn / pnpm / bun

### Steps
1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```
